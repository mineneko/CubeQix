# CubeQix
---
## 目標
- キューブの表面の75%以上を、90秒以内に浸食すること

## 操作
- 走行中にタップ（クリック）：テトラ（自機）が進行方向の右へ90°曲がる
- テトラは立方体の辺に着くと停止する
- 停止中にタップ（クリック）：隣接した面へ走り出す

## 基本ルール
- テトラが走ると軌跡が残る
- 軌跡で囲うか、軌跡が立方体の辺や浸食済みの領域に届くと、浸食成立
- 囲んだエリアのうち、敵がいない側を浸食する
- 残刻か残命が0になると失敗となり、ゲーム終了

## 残命について
- テトラの軌跡を追走する『ヒバナ』に追いつかれると残命-1
- ヒバナは、テトラが辺に着くと消える
- テトラが辺の敵や面の敵に触れると残命-1
- 辺で止まったまま3秒たつと残命-1

## 軌跡について
- 敵が触れるか、ヒバナに追いつかれると、軌跡は消える

## 残刻ボーナス
- 敵を狭いエリアに閉じ込めると撃破でき、残刻+5秒
